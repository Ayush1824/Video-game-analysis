# 🎮 LEVEL UP: Global Gaming Insights  

## 📊 Project Overview  
**Level Up: Global Gaming Insights** is an interactive **Power BI dashboard** designed to visualize and analyze **global gaming trends**.  
It provides deep insights into **sales performance**, **engagement patterns**, **regional distributions**, and **top-performing publishers and platforms** in the gaming industry.  

This project showcases how **data visualization** can transform raw gaming data into powerful insights — helping developers, analysts, and enthusiasts understand the market better.  

---

## 🚀 Key Insights  
- 🕹️ **Total Global Sales:** 8.92K units  
- ⭐ **Average Rating:** 3.66  
- 🔥 **Total Engagement:** 6M players  
- 🏆 **Top Publisher:** 10TACLE Studios  
- 🎮 **Top Performing Platform:** PlayStation 2 (PS2)  

---

## 📈 Dashboard Components  

| Section | Description |
|----------|-------------|
| **Global Sales Year by Year** | Line chart showing annual sales trends from 1990 to 2020. |
| **Regional Sales** | Bar chart comparing sales across NA, EU, and JP by game genre. |
| **Top Publisher** | Horizontal bar chart highlighting publishers with highest global sales. |
| **Total Engagement by Title** | Displays most engaging titles like *GTA*, *Minecraft*, and *Elden Ring*. |
| **Wishlist and Backlog Relation** | Bubble chart showing relation between player interest and engagement. |
| **Globally Regional Sales** | Donut chart showing contribution of each region to global sales. |

## 🧠 Tools & Technologies Used  
- **Power BI** – for building interactive dashboards  
- **Excel / CSV** – for data cleaning and pre-processing  
- **Power Query** – for transforming raw data  
- **DAX (Data Analysis Expressions)** – for calculated KPIs and insights  

---

## 🗂️ Dataset Information  
The dataset includes information about global video game sales and engagement.  
Main columns used:  
- `Title`  
- `Publisher`  
- `Genre`  
- `Platform`  
- `Global_Sales`, `NA_Sales`, `EU_Sales`, `JP_Sales`  
- `User_Rating`  
- `Engagement`
